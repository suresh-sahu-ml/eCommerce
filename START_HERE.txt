🚀 5-MINUTE QUICK START
════════════════════════════════════════════════════════════════════════════

STEP 1: Start Oracle Database (if you have Docker)
─────────────────────────────────────────────────
  docker run -d --name oracle-perfume -p 1521:1521 `
    -e ORACLE_PWD=OraclePass123 `
    container-registry.oracle.com/database/free:latest

  Wait for: "DATABASE IS READY TO USE!" in logs


STEP 2: Set Environment Variables
─────────────────────────────────
  Open PowerShell and run:

  $env:DB_URL = "jdbc:oracle:thin:@localhost:1521:ORCL"
  $env:DB_USERNAME = "system"
  $env:DB_PASSWORD = "OraclePass123"
  $env:AZURE_CIAM_ISSUER_URI = "https://YOUR_TENANT.b2clogin.com/TENANT_ID/v2.0/"
  $env:AZURE_CIAM_JWK_SET_URI = "https://YOUR_TENANT.b2clogin.com/TENANT.onmicrosoft.com/discovery/v2.0/keys"


STEP 3: Build Application
─────────────────────────
  cd d:\The-Perfume-Shop
  ./gradlew clean build

  Wait for: "BUILD SUCCESSFUL"


STEP 4: Start Application
─────────────────────────
  ./gradlew bootRun

  Wait for: "Started PerfumeShopApplication"
  Application runs on: http://localhost:8080/api


STEP 5: Test It Works
─────────────────────
  Open new PowerShell window:

  curl http://localhost:8080/api/products

  Expected: Returns JSON array with products


✅ NOW RUNNING! See TESTING_COMPLETE_FLOW.md for more tests

─────────────────────────────────────────────────
  • Copy sample values from SETUP_GUIDE.md

OPTION B: Setup Your Own Azure AD B2C (Production)
──────────────────────────────────────────────────
  1. Go to https://portal.azure.com
  2. Create Azure AD B2C tenant (perfume-shop-b2c)
  3. Register application (Perfume Shop API)
  4. Get credentials:

🔑 GETTING JWT TOKEN FROM AZURE CIAM
════════════════════════════════════════════════════════════════════════════

The "sub" claim in the JWT is the Azure CIAM Object ID
This links the external identity to your user in the database

Steps:
  1. Create user in your Azure AD B2C tenant
  2. Get JWT token (using PowerShell script or Portal)
  3. Decode at https://jwt.io to verify "sub" claim
  4. Use token with Bearer header in API requests

See SETUP_GUIDE.md - Part 3 for detailed steps with code examples

📞 TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════

Problem: Application won't start
Solution:
  1. Check Java 21 installed: java --version
  2. Check Oracle running: docker ps
  3. Check environment variables: $env:DB_URL
  4. See TESTING_COMPLETE_FLOW.md - Troubleshooting Matrix

Problem: Database connection refused
Solution:
  1. Start Oracle: docker start oracle-perfume
  2. Wait for startup: docker logs oracle-perfume
  3. Verify connection: sqlplus system/OraclePass123@localhost:1521/ORCL

Problem: JWT token rejected
Solution:
  1. Verify token is not expired
  2. Check issuer URI matches Azure CIAM tenant
  3. Verify "sub" claim exists in token
  4. Use https://jwt.io to decode and verify

Problem: API returns 401 Unauthorized
Solution:
  1. Ensure Bearer token in Authorization header
  2. Get fresh token from Azure CIAM
  3. Check token hasn't expired
